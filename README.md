# Minecraft modpack

Fabric modpack for Minecraft **26.3** (private — for friends on the server).

## Install

1. Install **Fabric** for Minecraft 26.3: run `fabric-installer-1.1.2.exe`, or create a Fabric 26.3 instance in Prism Launcher / the Modrinth app.
2. Copy everything in `mods/` into the instance's `mods` folder.
3. Copy the zips in `resources packs/` into `resourcepacks`, and `shaders packs/` into `shaderpacks`.
4. Start the game and turn on the resource packs and shader in Options.

## What's in it

- `mods/` — 45 Fabric mods (Sodium, Iris, Distant Horizons, Serene Seasons, Simple Voice Chat, JEI, Xaero's World Map, …)
- `resources packs/` — 7 resource packs (Fresh Animations, Stay True, Weskerson's packs)
- `shaders packs/` — Photon shaders

These files belong to their authors; this repo stays private and is only for our group.
